# Commands

Run `dp <command> --help` for full details on any command. Commands are grouped below by what they do:

- [Transformations](./transformations.md) — process the stream lazily, one record at a time
- [Stateful Operations](./stateful.md) — buffer the stream (or spill to disk) to produce their result
- [Aggregations](./aggregations.md) — reduce the stream to a single summary record
- [Schema & Formatting](./schema-formatting.md) — inspect or convert between formats
- [Utility](./utility.md) — completions, man pages, and multi-stage pipeline files
