# Utility

- `completions <shell>`: Prints a shell completion script for `bash`, `zsh`, `fish`, `powershell`, or `elvish`. See [Installation → Shell completions](../installation.md#shell-completions).
- `man`: Prints a troff-formatted man page. See [Installation → Man page](../installation.md#man-page).
- `run <file>`: Runs a multi-stage pipeline defined in a TOML file, instead of chaining many `dp` invocations with shell pipes. See [Pipeline Files](../pipeline-files.md).
